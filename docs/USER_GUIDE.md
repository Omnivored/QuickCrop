# QuickCrop 使用指南

适用版本：1.3.1。返回 [项目首页](../README.md)，查看 [详细图文与动图演示](DEMO.md)。

面向 Windows 10/11（64 位）的本地图片查看与连续裁剪工具。不上传图片，不需要联网。

## 运行

- 从 [发布页](https://github.com/Omnivored/QuickCrop/releases/latest) 下载压缩包，解压后运行其中的 `QuickCrop.exe`。
- `QuickCrop-1.3.1-Light.zip`：轻量版，需要安装 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)。不是仅安装 .NET Runtime 或 ASP.NET Core Runtime。
- `QuickCrop-1.3.1-Portable.zip`：自带运行环境版，不需要安装 .NET，可复制整个文件夹使用。
- 程序未作商业代码签名。首次运行时 Windows 可能显示未知发布者。

## 裁剪缩放、预览与成品列表

- 裁剪和预览界面均支持滚轮缩放，以鼠标所在位置为中心；也可使用放大、缩小、适应窗口和实际像素按钮。按住鼠标中键可平移图片，预览中也可直接左键拖动。
- 调整选框后松开鼠标，立即放大显示所选区域的裁剪预览，隐藏选框和网格。点击返回箭头或按 `Esc` 可回到刚才的选框和视图继续调整；也可随时点击眼睛图标预览。
- 撤销按钮或 `Ctrl+Z` 可回退上一次选区调整，最多保留当前模式下 64 次调整；更换尺寸或图片后清空旧选区历史。预览和撤销本身不写文件，保存前不改动原图。
- 放大时按需补载高清预览，保留裁剪坐标、旋转及翻转状态；最终导出仍读取原图像素。
- 点击尺寸后，裁剪框按所选比例居中铺满原图可容纳的最大范围，不再预留额外边距；进入裁剪、切换下一张和重置选区同样适用。
- 保存后，成品和新缩略图替代原图在列表中的位置；下一张自动选择尚未处理的图片，已完成的成品仍可点回查看。全部完成后停留在最后保存的成品，不再清空列表。
- 本轮刷新会保留成品的位置，包括保存到其他目录的成品，同时不会将其重新加入自动处理队列。重新打开文件夹会开始新的一轮扫描。

## 尺寸模板与批量固定尺寸

- 裁剪面板使用三列两行的六格选择区，前五格默认依次为 `9:16`、`2:3`、`1:1`、`16:9`、`3:2`；第六格“更多”下拉列表包含其他模板及自由、原图比例、自定义比例、固定选区像素和圆形裁剪。
- 点击“尺寸模板”旁的齿轮，或从“设置”进入“尺寸模板”，可以新建、命名、编辑和删除模板，并指定前台五个位置；选择已占用的位置会互换，不出现重复按钮。
- “比例”模板只限定宽高比，导出保留所选区域的原始像素；“像素”模板同时限定比例和成品尺寸，例如命名为“竖图封面”的 `1080 × 1920` 模板会导出精确的 `1080 × 1920` 像素图片。选区较小时也会放大到指定输出尺寸。
- 勾选“固定裁剪尺寸”后，记住勾选时的比例和像素输出尺寸，后续图片自动沿用，仍可调整选框位置和范围；取消勾选后可以重新选尺寸。固定期间尺寸按钮和宽高交换停用，避免误改批次规格。
- 模板、前台位置、所选模式和固定尺寸状态会保存在本机，重启后继续沿用；模板编辑窗口中点击“取消”不会应用修改。
- 本版同时包含下面的裁剪入口与浏览旋转方向修复。

### 新建一个精确像素模板

1. 进入裁剪，点击“尺寸模板”右侧的齿轮；也可从设置中的“尺寸模板”进入。
2. 点击加号，在表格新行中填写名称，例如“手机壁纸”。
3. 类型选择“像素”，宽填 `1080`，高填 `1920`。名称最多 40 个字符，不能与其他模板重名。
4. 在窗口下方“前台五个尺寸”中，将某个位置设为“手机壁纸”。只想放在“更多”中则不修改这五个位置。
5. 点击保存，选择该模板。侧栏会显示输出尺寸 `1080 × 1920 px`。
6. 要连续处理同一规格，勾选“固定裁剪尺寸”。保存后下一张自动沿用这套规格。

如果只想限制形状而不缩放输出，类型应选择“比例”，宽高可填 `9` 和 `16`。例如一个 `600 × 1067` 左右的选区会保留这些原始像素，不会因选择 `9:16` 就自动导出为 `1080 × 1920`。

像素模板宽高必须为正整数，单边不超过 50000，总像素不超过 2 亿。模板编辑点击“取消”不应用修改；从设置中进入模板编辑后，还需要保存设置才能应用整个设置草稿。

### 返回调整与撤销的区别

| 操作 | 结果 |
| --- | --- |
| 预览中点击返回箭头或按 `Esc` | 保留刚才的选框，恢复进入预览前的缩放和平移，继续调整 |
| 点击撤销箭头或按 `Ctrl+Z` | 回到上一次选区调整之前的选框；预览中使用时先回到编辑 |
| 编辑中按 `Esc` 或点击取消 | 放弃本次裁剪，恢复浏览，不写文件，不归档 |
| 点击保存或按 `Ctrl+S` | 导出当前选区、归档原图，并转向下一张未处理图片 |

撤销只针对当前图片、当前裁剪模式下的选区，不会撤销已经保存的文件操作，也不是从回收站恢复图片。切换尺寸或重置选区会清空选区撤销历史。

## 裁剪入口与旋转方向

- 点击裁剪或触发快捷键立即进入裁剪页面；没有目录确认窗口，也不执行任何中间设置流程。
- 成品目录、原图归档目录和成品格式统一在“设置”中修改并保存；默认直接使用原图所在目录及其中的“原图归档”子目录。
- 浏览旋转按图片独立记录，切图、刷新、切换文件夹及重启后仍保留方向；记录存于本机设置目录，不覆盖原图。
- 快捷键使用本次按键事件的修饰键状态匹配，识别输入法处理后的实际按键，不再二次读取可能变化的键盘状态。
- 新增固定的 `F2` 裁剪入口，不受 `Ctrl+Space` 输入法切换冲突影响；原有自定义快捷键继续保留。
- 快捷键立即标记为已处理，并屏蔽长按重复触发。
- 回归测试覆盖无弹窗的实际裁剪入口、设置中的目录编辑、旋转方向记忆、默认与自定义快捷键和 `F2` 入口。

## 删除与旋转

- `Delete` 直接移入回收站，不再弹出确认，旧版本的确认设置也不再生效。
- `Ctrl+←` 逆时针旋转 90°，`Ctrl+→` 顺时针旋转 90°，浏览和裁剪时均可使用。
- 长按删除或旋转快捷键不连续触发；无法回收时保留原文件，不转为永久删除。

## 大图加载

- 浏览时按窗口尺寸准备预览，JPEG、PNG、BMP、GIF、TIFF、ICO 优先使用 Windows 原生解码；其他格式保留内置解码后备路径。
- 取消“压成 PNG 再解码显示”的中转，后备路径直接传递像素。
- 后台预读后两张、前一张图片，最多缓存 8 张、128 MiB 预览。该上限不包含当前显示图、解码中的临时缓冲和缩略图；单张大于缓存预算一半的高清图不进入缓存。
- 快速切图时取消过期请求，正在执行且无法中断的原生解码完成后丢弃结果，不覆盖当前图片；前台与后台预读分别限制并发。
- 缩略图延后生成，并复用已有预览，避免与主图争抢加载资源。缩略图单独复制为小图，不保留大图引用。
- 裁剪、旋转和翻转先操作预览和选区坐标；保存时才读取原图并应用同样的变换，成品不会使用缩小后的预览像素。
- 查看、裁剪和预览模式放大时自动补载高清细节，切回其他图片时可释放。取消裁剪直接恢复已有预览，不再重新解码。
- 文件大小或修改时间变化时自动使预览缓存失效；刷新、新开文件夹、保存、删除都会相应清理缓存。

可以使用开发测试中的 `--perf` 选项生成本机样例耗时记录。它只比较固定样例的预览准备时间，不包含完整界面响应，不代表所有图片，也不是与 WPS 的对照测试。详见 [构建与验证](TESTING.md)。

## 连续裁剪

1. 打开图片文件夹，可拖入文件夹或单张图片。
2. 需要自定义保存位置时，打开“设置”修改成品目录、原图归档目录、成品格式；不需要修改则跳过。
3. 成品目录默认使用每张原图所在目录；原图默认归档至“原图归档”子目录，设置会被记住。
4. 进入裁剪，选择右侧的尺寸模板，选框自动按比例铺满。拖动选框或八个控制点后松开鼠标，自动放大预览；按 `Esc` 返回继续调整，`Ctrl+Z` 撤销上一次调整。其他尺寸和裁剪方式在第六格“更多”中，新增与命名模板使用旁边的齿轮。
5. 批量裁成同一比例或像素尺寸时，选好尺寸后勾选“固定裁剪尺寸”；切换到后续图片无需再次选择。
6. 点击“保存并下一张”或按 `Ctrl+S`，自动完成：生成成品 → 将原图移入归档目录 → 显示下一张并继续裁剪。保存时不再弹出文件选择窗口。
7. 成品替代原图在列表中的位置，已处理图片仍可查看，但自动切图会跳过它们；本轮刷新保留成品。再次打开文件夹会开始新的一轮。

保存位置和原图目录相同时，成品使用原文件名，未经修改的原文件仍完整保存在归档目录。其他同名冲突自动添加 `_2`、`_3` 等编号，不覆盖其他文件。输出生成失败时不会移动原图；归档后发布失败会尝试将原图还原，并明确报告文件位置。

成品默认沿用可写入的原格式，也可预设 PNG、JPEG、WebP、TIFF、BMP。GIF、HEIC、AVIF、PSD 等输入默认转 PNG；圆形裁剪自动保存 PNG 透明背景。

## 按键

| 按键 | 操作 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张 |
| `Delete` | 直接将当前图片移入 Windows 回收站，不弹出确认 |
| `Ctrl+←` / `Ctrl+→` | 逆时针 / 顺时针旋转 90°，浏览和裁剪时均可使用 |
| `Ctrl+Space` | 进入裁剪，可在设置中更改 |
| `F2` | 进入裁剪，固定备用快捷键 |
| `Ctrl+S` / 裁剪时 `Enter` | 保存、归档原图、继续下一张 |
| `Esc` | 从预览返回调整；编辑时取消当前裁剪 / 退出全屏 |
| 裁剪时 `Ctrl+Z` | 撤销上一次选区调整 |
| 裁剪时方向键 | 移动选区 1 像素，按住 `Shift` 为 10 像素 |
| `Ctrl+O` | 打开文件夹 |
| `F5` | 刷新当前图片列表，保留本轮裁剪成品 |
| `F` / `1` | 适应窗口 / 实际像素 |
| `F11` | 全屏 |
| 滚轮 / `+` / `-` | 缩放，查看、裁剪和预览时均可使用 |
| 按住鼠标中键拖动 | 平移图片，不移动裁剪选框对应的原图区域 |
| `Home` / `End` | 第一张 / 最后一张 |

注意：`Ctrl+Space` 可能被中文输入法占用；可直接使用 `F2` 或点击顶部裁剪按钮，也可在设置中改成 `Ctrl+Shift+X` 等组合键。快捷键只在本程序有焦点时生效，不注册系统全局快捷键。

浏览旋转方向按图片记住，切到其他图片再回来仍保持离开时的状态，刷新、重新打开文件夹和重启程序后也会恢复。方向记录单独存储，不自动写入或覆盖原图；原文件在外部发生变化后，其旧方向记录会失效。进入裁剪会沿用当前显示方向；保存时将旋转写入成品并归档未经修改的原图，成品不会重复应用方向记录。取消裁剪恢复进入裁剪前的浏览方向。编辑文字时 `Ctrl+←` / `Ctrl+→` 保留光标移动功能。按住 `Delete` 或旋转组合键不会连续触发，避免误删或反复旋转；移入回收站后可从 Windows 回收站还原。

## 格式与限制

支持读取 JPEG/JFIF、PNG、BMP/DIB、GIF、TIFF、WebP、HEIC/HEIF、AVIF、ICO、TGA、PSD、PPM/PGM/PBM、PCX。使用内置图片解码库，不依赖 Windows 商店 HEIF 扩展。

- 动图、多页 TIFF 只显示和导出第一帧或第一页；不保留动画。
- PSD 读取合成图，不编辑图层。此版本不包含相机 RAW 和 SVG/PDF 支持。
- 自动按照片方向信息校正。导出会移除失效的 EXIF、GPS 和嵌入缩略图，保留 ICC 色彩描述。
- 使用 8 位通道处理；不作为高位深或 HDR 母版编辑器。
- 大于 2 亿像素的图像拒绝读取，以限制内存压力。
- 设置文件保存在 `%LOCALAPPDATA%/QuickCrop/settings.json`。
- 浏览旋转方向记录保存在 `%LOCALAPPDATA%/QuickCrop/view-rotations.json`。
- 删除原图使用 Windows 回收站；归档移动不使用回收站。取消裁剪不写文件，也不归档原图。
- 保存中不要拔出移动硬盘或强制结束进程。程序有失败回退，但不能保证断电/进程终止时的跨文件原子性。

## 开发与测试

使用 .NET 10 SDK：

```powershell
dotnet run --project QuickCrop.csproj
dotnet run --project tests -c Release -p:BaseOutputPath=bin/verify/ -- --ui
dotnet run --project tests -c Release -p:BaseOutputPath=bin/verify/ -- --perf
dotnet run --project tests -c Release -p:BaseOutputPath=bin/verify/ -- --recycle
.\build.ps1
.\build.ps1 -Standalone
```

`--ui` 使用独立临时图片和设置，验证无弹窗裁剪入口、目录设置、浏览旋转方向记忆、旋转快捷键、高清加载保留方向、取消裁剪恢复方向、原分辨率旋转导出、保存、归档、自动切图、六格模板选择、模板命名与前台位置互换、混合横竖图固定比例批次、精确像素尺寸批次、设置持久化、滚轮缩放、松开鼠标自动预览、返回编辑、撤销、最大选框、成品缩略图替换、已完成图片跳过及外部成品刷新，并输出界面截图至 `output/qa`。配合 `--recycle` 验证无确认删除、自动切到下一张、删除最后一张、旧设置兼容、文件占用失败保护；仅将新生成的测试图片送入回收站。测试不会操作用户原图。
